Exercise 02: Wiring the Repository

Module 03: Data Persistence | ICICI Bank API Services | Day 3

⏱ 60 min · Individual

Background

In Exercise 01 you made Customer a proper JPA entity. Now you need two things:

  • CustomerRepository — the interface that gives you database operations for free
  • Updated CustomerController — replace ArrayList code with repository calls

1 Create CustomerRepository (10 min)

Create: src/main/java/com/icici/banking/repository/CustomerRepository.java

package com.icici.banking.repository;

import com.icici.banking.model.Customer;
import org.springframework.data.jpa.repository.JpaRepository;
import org.springframework.stereotype.Repository;

@Repository
public interface CustomerRepository extends JpaRepository<Customer, String> {
    // No methods needed yet — JpaRepository provides all CRUD for free
}
💡 Notice: This is an interface, not a class. Spring generates the implementation at startup.

2 Inject Repository into Controller (5 min)

In CustomerController.java:

Remove:

private final List<Customer> customers = new ArrayList<>(List.of(...));

Add:

@Autowired
private CustomerRepository customerRepository;
// Keep the AtomicInteger for CUST-style ID generation
private static final AtomicInteger counter = new AtomicInteger(1003);

3 Replace ArrayList Operations (30 min)

getAllCustomers

Before:

return customers;

After:

return customerRepository.findAll();

getCustomer

Before:

return customers.stream().filter(c -> c.getCustomerId().equals(customerId))
        .findFirst().map(ResponseEntity::ok).orElse(ResponseEntity.notFound().build());

After:

return customerRepository.findById(customerId)
        .map(ResponseEntity::ok).orElse(ResponseEntity.notFound().build());

createCustomer

Before:

customers.add(customer);
return ResponseEntity.status(201).body(customer);

After:

Customer saved = customerRepository.save(customer);
return ResponseEntity.status(201).body(saved);

replaceCustomer

Before:

for (int i = 0; i < customers.size(); i++) {
    if (customers.get(i).getCustomerId().equals(customerId)) {
        updated.setCustomerId(customerId);
        customers.set(i, updated);
        return ResponseEntity.ok(updated);
    }
}
return ResponseEntity.notFound().build();

After:

if (!customerRepository.existsById(customerId)) {
    return ResponseEntity.notFound().build();
}
updated.setCustomerId(customerId);
return ResponseEntity.ok(customerRepository.save(updated));

updateEmail

After:

return customerRepository.findById(customerId).map(c -> {
    c.setEmail(patch.getEmail());
    return ResponseEntity.ok(customerRepository.save(c));
}).orElse(ResponseEntity.notFound().build());

deleteCustomer

After:

if (!customerRepository.existsById(customerId)) {
    return ResponseEntity.notFound().build();
}
customerRepository.deleteById(customerId);
return ResponseEntity.noContent().build();

5 Test All Endpoints (10 min)

EndpointExpected SQL in console

Verification Checklist

  • GET /api/v1/customers returns 3 seed customers
  • POST creates a customer that persists across GET calls
  • DELETE removes the customer — subsequent GET returns 404
  • SQL queries visible in application console
  • No compilation errors
