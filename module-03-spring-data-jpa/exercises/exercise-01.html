Exercise 01: From POJO to Entity

Module 03: Data Persistence | ICICI Bank API Services | Day 3

⏱ 45 min · Individual

Background

Your Customer class is currently a plain Java object (POJO). Spring Data JPA needs it decorated with annotations so Hibernate knows how to map it to a database table.

BeforeAfter
public class Customer@Entity @Table(name="customers") public class Customer
private String customerId@Id @Column(name="customer_id") private String customerId
No default constructorpublic Customer() {} added (required by JPA)
ArrayList onlyWorks with any JPA-compatible database

1 Add JPA Dependency to pom.xml (5 min)

Open pom.xml. Find the commented JPA + H2 section and uncomment it:

<dependency>
  <groupId>org.springframework.boot</groupId>
  <artifactId>spring-boot-starter-data-jpa</artifactId>
</dependency>
<dependency>
  <groupId>com.h2database</groupId>
  <artifactId>h2</artifactId>
  <scope>runtime</scope>
</dependency>

Reload Maven: right-click pom.xml → Maven → Reload Project.

2 Configure H2 + JPA in application.yml (5 min)

spring:
  datasource:
    url: jdbc:h2:mem:icicidb;DB_CLOSE_DELAY=-1
    driver-class-name: org.h2.Driver
    username: sa
    password: ""
  h2:
    console:
      enabled: true
      path: /h2-console
  jpa:
    hibernate:
      ddl-auto: create-drop
    show-sql: true

3 Annotate Customer.java (15 min)

import jakarta.persistence.Column;
import jakarta.persistence.Entity;
import jakarta.persistence.Id;
import jakarta.persistence.Table;

@Entity
@Table(name = "customers")
public class Customer {

    @Id
    @Column(name = "customer_id", nullable = false, unique = true)
    private String customerId;

    @Column(name = "name", nullable = false)
    private String name;

    @Column(name = "email", unique = true)
    private String email;

    @Column(name = "mobile")
    private String mobile;

    // Required by JPA
    public Customer() {}

    // Existing constructor + getters/setters unchanged
}

4 Start the Application (5 min)

Run the app. In the console you should see Hibernate generate the table:

Hibernate: create table customers (
    customer_id varchar(255) not null,
    email varchar(255) unique,
    mobile varchar(255),
    name varchar(255) not null,
    primary key (customer_id)
)
💡 Tip: If you don't see this, check show-sql: true is in application.yml and the JPA dependency loaded.

5 Verify in H2 Console (10 min)

Open http://localhost:8080/h2-console:

  • JDBC URL: jdbc:h2:mem:icicidb
  • Username: sa  ·  Password: (leave blank)

Click Connect, then run: SELECT * FROM CUSTOMERS; — 0 rows is correct at this stage.

Verification Checklist

  • Console shows create table customers on startup
  • H2 console connects successfully
  • SELECT * FROM CUSTOMERS returns 0 rows (no error)
  • Application starts without errors
