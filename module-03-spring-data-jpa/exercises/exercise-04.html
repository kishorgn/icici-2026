Account Entity Specification

FieldJava TypeColumnConstraints
accountNumberStringaccount_number@Id, NOT NULL, UNIQUE
customerIdStringcustomer_idNOT NULL
balanceBigDecimalbalanceNOT NULL
accountTypeStringaccount_typeNOT NULL (SAVINGS / CURRENT / FIXED_DEPOSIT)
statusStringstatusNOT NULL (ACTIVE / SUSPENDED / CLOSED)

Repository Requirements

  • Extend JpaRepository<Account, String>
  • Derived: findByCustomerId(String customerId) returns List<Account>
  • Derived: findByAccountType(String accountType) returns List<Account>
  • @Query: find accounts where balance > given amount

Seed Data

INSERT INTO accounts (account_number, customer_id, balance, account_type, status) VALUES
    ('ACC100101', 'CUST1001', 15000.00, 'SAVINGS', 'ACTIVE'),

findByCustomerId("CUST1002") returns 2 accounts
Application starts without errors

Common Pitfalls

PitfallFix
int/long for balanceUse BigDecimal — precision matters for money
No no-arg constructorAdd public Account() {} — Hibernate requires it
Quoted numbers in data.sqlBalance must be a number, not a string: 15000.00 not '15000.00'
