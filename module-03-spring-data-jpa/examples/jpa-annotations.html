JPA Annotations — Quick Reference

Module 03 | ICICI Bank API Services | Day 3

Class-Level Annotations

AnnotationPurposeExample
@EntityMarks the class as a JPA entity — maps to a table@Entity public class Customer {}
@TableCustomise the table name@Table(name = "customers")
@MappedSuperclassBase class with shared fields; not a table itself@MappedSuperclass public class BaseEntity {}

Field-Level Annotations

AnnotationPurposeExample
@IdMarks the primary key field@Id private String customerId;
@GeneratedValueAuto-generate PK (Long/Integer IDs)@GeneratedValue(strategy = GenerationType.IDENTITY)
@ColumnMap field to column with options@Column(name = "customer_id", nullable = false, unique = true)
@TransientField NOT persisted to DB@Transient private String displayLabel;
@LobLarge object column (CLOB/BLOB)@Lob private String notes;
@EnumeratedPersist enum as STRING or ORDINAL@Enumerated(EnumType.STRING) private Status status;
@CreationTimestampAuto-set on INSERT (Hibernate)@CreationTimestamp private LocalDateTime createdAt;
@UpdateTimestampAuto-set on UPDATE (Hibernate)@UpdateTimestamp private LocalDateTime updatedAt;

Minimal Entity Template

@Entity
@Table(name = "my_table")
public class MyEntity {

    @Id
    @Column(name = "id", nullable = false)
    private String id;

    @Column(name = "name", nullable = false)
    private String name;

    public MyEntity() {}  // JPA requires this

    public MyEntity(String id, String name) {
        this.id = id;
        this.name = name;
    }

    // getters + setters
}
