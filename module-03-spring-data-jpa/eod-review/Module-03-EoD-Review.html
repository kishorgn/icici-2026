Key Concepts

@Entity = Table

@Entity @Table(name="customers")

Every class annotated @Entity gets its own database table. Hibernate creates it automatically (with ddl-auto: create-drop).

@Id = Primary Key

@Id @Column(name="customer_id")

We kept String IDs (CUST1001). Use @GeneratedValue(IDENTITY) when the DB should auto-generate a Long.

JpaRepository

extends JpaRepository<T, ID>

Zero implementations written. Spring provides findAll, save, deleteById etc. You just declare the interface.

Derived Queries

findByEmail(String email)

Method name → SQL. Spring parses findBy + FieldName and generates WHERE email = ? automatically.

@Query (JPQL)

"SELECT c FROM Customer c WHERE..."

JPQL uses class names, not table names. For complex queries where method names become unreadable.

H2 Console

localhost:8080/h2-console

Browser-based SQL editor. See your data, run queries, debug schema. JDBC URL must match application.yml exactly.
