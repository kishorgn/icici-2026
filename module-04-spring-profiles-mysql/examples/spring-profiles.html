📁 File Structure — Three Properties Files

Spring Boot loads these files in order: common first, then the active profile on top (profile values override common values).

FileLoaded WhenPurpose
application.propertiesAlwaysCommon settings — server port, actuator, app name
application-dev.propertiesProfile = devLocal MySQL, show-sql=true, ddl-auto=update
application-prod.propertiesProfile = prodProd MySQL via env vars, show-sql=false, ddl-auto=validate

application.properties (common)

application.properties
server.port=8080
spring.application.name=icici-banking-api

# Active profile
spring.profiles.active=dev

# Actuator
management.endpoints.web.exposure.include=health,info,metrics
management.endpoint.health.show-details=always

# App info at /actuator/info
info.app.name=ICICI Banking API
info.app.version=1.0.0

application-dev.properties

application-dev.properties
spring.datasource.url=jdbc:mysql://localhost:3306/icicidb\
?useSSL=false&serverTimezone=UTC\
&allowPublicKeyRetrieval=true
spring.datasource.driver-class-name=\
    com.mysql.cj.jdbc.Driver
spring.datasource.username=root
spring.datasource.password=root

spring.jpa.database-platform=\
    org.hibernate.dialect.MySQLDialect
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true
spring.jpa.properties.hibernate.format_sql=true
⚠️ ddl-auto=update — Hibernate auto-creates or alters tables. Dev only.

application-prod.properties

application-prod.properties
# Credentials from environment variables
spring.datasource.url=\
    ${DB_URL:jdbc:mysql://localhost:3306/icicidb}
spring.datasource.driver-class-name=\
    com.mysql.cj.jdbc.Driver
spring.datasource.username=${DB_USERNAME:root}
spring.datasource.password=${DB_PASSWORD:root}

spring.jpa.database-platform=\
    org.hibernate.dialect.MySQLDialect
spring.jpa.hibernate.ddl-auto=validate
spring.jpa.show-sql=false
⚠️ ddl-auto=validate — schema must already exist; app fails fast if columns are missing.

⚙️ Three Ways to Activate a Profile

#MethodCommand / SettingPrecedence
1 In application.properties spring.profiles.active=dev Lowest — overridden by 2 and 3
2 JVM argument java -Dspring.profiles.active=prod -jar app.jar Overrides properties file
3 Environment variable export SPRING_PROFILES_ACTIVE=prod Highest — overrides both above
💡 In Maven: mvn spring-boot:run -Dspring-boot.run.jvmArguments="-Dspring.profiles.active=prod"

🗄️ ddl-auto Values — When to Use Each

ValueWhat Hibernate DoesUse In
createDrops all tables, creates fresh on startup — ALL DATA IS LOSTNever in production
create-dropCreates tables on startup, drops them on shutdownAutomated testing only
updateAdds missing columns/tables; never removes columnsDev — safe, data preserved
validateChecks schema matches entities; app fails if mismatchProduction
noneDoes nothing to the schemaWhen you manage schema externally
⚠️ ddl-auto=create drops all data on every application restart — never use it when you need to keep data.

@Profile — Profile-Specific Beans

Use @Profile to register a bean only in a specific profile:

@Component
@Profile("dev")
public class DevDataLoader
         implements CommandLineRunner {

  public void run(String... args) {
    // insert sample data for dev
  }
}
💡 This bean runs ONLY when the active profile is dev. Production is unaffected.
