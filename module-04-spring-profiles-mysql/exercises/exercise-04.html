The Challenge

You have now seen the full pattern twice — with Customer (Day 3) and with Transaction (Exercise 02 today). It is time to apply it independently.

You and your pair will add a complete Account feature to the banking API — entity, repository, and controller. ddl-auto=update in the dev profile will create the accounts table automatically when you start the app.

Try building from memory first. Use today's reference code only if you are stuck for more than 5 minutes.

What You Are Building

An Account has these fields. Hibernate will auto-create the accounts table in MySQL from your entity annotations:

Java FieldDB ColumnTypeNotes
accountIdaccount_idStringPrimary key, format ACC10001
customerIdcustomer_idStringLinks to a customer
accountTypeaccount_typeString"SAVINGS" or "CURRENT"
balancebalanceBigDecimalAlways use BigDecimal for money

Requirements (What to Build)

✓
  1. Account.java — JPA entity with all four fields, @Entity, @Table(name="accounts"), @Id, @Column annotations, and a no-arg constructor plus getters/setters.
  2. AccountRepository.java — extends JpaRepository<Account, String>, with:
    • List<Account> findByCustomerId(String customerId)
    • Page<Account> findAll(Pageable pageable)
  3. AccountController.java — base path /api/v1/accounts, with these endpoints:
    • GET /api/v1/accounts — return all accounts
    • GET /api/v1/accounts/{accountId} — return one or 404
    • GET /api/v1/accounts/customer/{customerId} — all accounts for one customer
    • GET /api/v1/accounts/page — paginated: ?page=0&size=3&sort=balance
    • POST /api/v1/accounts — create, auto-generate accountId as ACC1XXXX
    • DELETE /api/v1/accounts/{accountId} — 204 No Content or 404

Hints

💡 ddl-auto=update in application-dev.properties means Hibernate auto-creates the accounts table on startup. No SQL scripts needed — just annotate the entity correctly and start the app.
💡 AccountId format: Start an AtomicInteger counter = new AtomicInteger(10000) in the controller, then use "ACC" + counter.incrementAndGet() for each new account.
💡 Import java.math.BigDecimal for the balance field. Use @Column(precision=15, scale=2) to control the MySQL column type (DECIMAL(15,2)).
💡 For the paginated endpoint, accept @RequestParam(defaultValue="0") int page and @RequestParam(defaultValue="5") int size — or use Spring's Pageable directly as a method parameter.
💡 Verify in MySQL: DESCRIBE accounts; should show your columns, and SELECT * FROM accounts; shows records you inserted via POST.
