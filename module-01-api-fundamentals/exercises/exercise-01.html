Module 01: API Fundamentals | ICICI Bank API Services

⏱ 45 min · Pair Exercise
Part A — Fill in the blanks (10 min)

Complete the table. Use: GET · POST · PUT · PATCH · DELETE

Method Action Banking example Request body? Success code
Read data Fetch account balance No 200
Create new Open a new account Yes
Replace all Update full customer profile 200
Update part Change only email address Yes 200
Remove Remove a beneficiary No
Remember: GET is the only method that must never have a request body and must never change data on the server.
Part B — Live Postman calls (15 min)

Open Postman and make each call. Record the status code and one thing you notice about the response.

1
GET https://jsonplaceholder.typicode.com/posts
Status code you got:   How many records?
2
GET https://jsonplaceholder.typicode.com/posts/1
Status code:   What changed in the URL?
3
POST https://jsonplaceholder.typicode.com/posts
Set Content-Type: application/json header. Send this body: 
{
  "title": "My first banking post",
  "body":  "Learning APIs at ICICI",
  "userId": 1
}
Status code:   What id was assigned?
4
PATCH https://jsonplaceholder.typicode.com/posts/1
Send body: { "title": "Updated title only" }
Status code:   Were other fields affected?
5
DELETE https://jsonplaceholder.typicode.com/posts/1
Status code:   What was in the response body?
