Day 2 Quiz — Spring Boot REST: Full CRUD

ICICI Bank API Services | 10 Questions | 10 Minutes

⏱ Time remaining: 10:00
Question 1 of 10
Which annotation tells Spring Boot to map an HTTP POST request to a controller method?
✅ @PostMapping maps HTTP POST requests to a method. @GetMapping maps GET, @RequestBody reads the body, @RequestMapping sets the base URL.
Question 2 of 10
What HTTP status code should a successful POST (resource creation) return?
✅ 201 Created is the correct status for successful resource creation. 200 OK is for successful reads/updates. 204 is for deletes.
Question 3 of 10
Which annotation reads a value from the URL path — e.g., the CUST1001 in /customers/CUST1001?
✅ @PathVariable extracts a value from a URL path segment like {customerId}. @RequestParam reads query parameters (?key=value). @RequestBody reads the JSON body.
Question 4 of 10
What is the correct ResponseEntity call for a successful DELETE operation?
✅ ResponseEntity.noContent().build() returns 204 No Content with no body — the correct REST convention for a successful delete. There is no .deleted() method.
Question 5 of 10
A client sends PUT /customers/CUST1001 with body: {"name":"New Name"} (no email, no mobile). What happens to the email and mobile fields?
✅ They become null/empty. PUT is a full replace — Spring deserializes only what's in the JSON. Missing fields become null. This is the key difference from PATCH.
Question 6 of 10
Why does the Day 2 CustomerController use new ArrayList<>(List.of(...)) instead of Arrays.asList(...)?
✅ Arrays.asList() returns a fixed-size list that does not support add() or remove(). For CRUD operations (POST adds, DELETE removes), we need a mutable ArrayList.
Question 7 of 10
Look at this code. What is wrong?

@PostMapping public Customer createCustomer(@RequestBody Customer customer) { customers.add(customer); return customer; }
✅ Two bugs: (1) Returns plain Customer → Spring defaults to 200 OK instead of 201 Created. Should use ResponseEntity.status(201).body(customer). (2) No ID is assigned — server must set customerId before adding.
Question 8 of 10
What does @RestController do that plain @Controller does not?
✅ @RestController = @Controller + @ResponseBody. @ResponseBody tells Spring to serialize the return value to JSON and write it to the response body, instead of resolving it as a view name.
Question 9 of 10
A customer wants to change only their email. Which HTTP method is the best choice?
✅ PATCH is designed for partial updates. PUT would require sending all fields (risky if the client doesn't have them all). PATCH sends only the changed field.
Question 10 of 10
Which of the following correctly declares a DELETE endpoint that returns 204 No Content on success and 404 if not found?
✅ Option B is correct: uses @DeleteMapping, ResponseEntity<Void>, checks removeIf() return value, returns 204 on success and 404 if not found. Option A returns void (no status control). C returns 200 with a body. D uses GET for a delete operation.
