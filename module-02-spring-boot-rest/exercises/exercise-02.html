PATCH Concept — PUT vs PATCH

⚡ PUT — Full Replace

Body must contain ALL fields.
Omit a field → it becomes null.
Replace the entire object.

🩹 PATCH — Partial Update

Body contains only changed fields.
Other fields are untouched.
Update specific part of the object.

Q.
Our PATCH endpoint updates only email. What would the request body look like?
