Module 02: Spring Boot REST | ICICI Bank API Services

⏱ ~60 minutes 👥 Pair Exercise

🏦 Scenario: ICICI Account Management API

ICICI Bank needs to expose Account management via REST. Customers can have multiple accounts (savings, current). Your task is to build AccountController.java — a complete CRUD controller — following the same patterns you learned for customers. This is a real extension of the project you've been working on.
